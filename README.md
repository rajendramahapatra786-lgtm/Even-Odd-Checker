# 🔢 Even Odd Checker

A simple, clean, and beginner-friendly **Even Odd Checker web application** that determines whether a given number is **Even** or **Odd** instantly.

The project is designed to demonstrate fundamental programming logic, user input handling, DOM manipulation, and basic frontend development.

---

## ✨ Features

- 🔢 Enter any number
- ⚡ Instantly check whether the number is **Even** or **Odd**
- ✅ Clear and simple result display
- 🎨 Clean and responsive user interface
- 🧩 Beginner-friendly JavaScript logic
- 📱 Works on desktop, tablet, and mobile browsers
- 🚫 Handles invalid/empty input appropriately

## 🧠 How It Works

The application follows a simple mathematical rule:

```text
number % 2 === 0
```

- If the remainder is `0`, the number is **Even**.
- Otherwise, the number is **Odd**.

### Example

```text
Input: 24
Output: 24 is Even
```

```text
Input: 17
Output: 17 is Odd
```
